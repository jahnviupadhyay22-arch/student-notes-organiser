# 📚 Student Notes Organiser

A clean, responsive web application designed to create, organize, and manage daily study notes with search and filtering features.

## 🚀 Live Demo
🔗 [Click here to view the live website](https://jahnviupadhyay22-arch.github.io/student-notes-organiser/)

## ✨ Features
- *Create & Manage Notes:* Add study notes with titles, subjects, and details.
- *Search & Filter:* Find notes instantly with keyword search.
- *Responsive UI:* Clean interface that adapts across laptops, tablets, and phones.
